# Evaluation

Measures whether the thesis holds. Contents:

- `scenarios/`: 14 tickets as a team would write them (CDC, events, files,
  gold definitions, schema drift, PII in free text, late CDC, a breaking
  change, an erasure request, a new adapter).
- `protocol.md`: how a run is done and what is logged.
- `baseline.yaml`: hand-built effort estimates, written before any run.
- `logs/`: one JSON-lines file per scenario run (`contractline eval-log`).
- `results.md`: generated by `contractline eval-report --out evaluation/results.md`.

Results so far are in [`results.md`](results.md). Read its "threats to
validity" section before quoting any number.
